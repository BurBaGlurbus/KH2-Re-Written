# Quarantined image research

`image_inspector` loads selected replacement textures directly from read-only KH2 package handles after a fresh complete source rehash. It is a research viewer, with no gameplay qualification or simulation. All input manifests/selections and output logs/captures belong in private external storage; never put source-derived artifacts in the checkout.

It runs inside the launcher: `"KH2RW Launcher.exe" image_inspector` (or `cargo run -p main --bin KH2RW --locked -- image_inspector`) followed by four arguments (the launcher's "Image viewer: Title screen" row passes its made `auto-title-selection.json`, T228): selected Steam installation, bound private manifest, explicit private image selection, and a new private JSONL log. Selection uses the original probe's source-bound schema, `inspect_hd_images: true`, and the explicitly chosen DDS CPU profile. Optional `--capture-dir` names an existing private directory; `--tour` captures all six views of each actual image; `--frames N` sets a safety limit (180–100000). Existing files are refused.

Controls: left/right change images; C composite; V stored RGB; R/G/B/A isolate channels; F fit; 1 native size; plus/minus zoom; Escape close. Tour mode preserves its state until each asynchronous capture completes and ignores view-changing keys. The window title carries the selected image/mode/dimensions and quarantine status. Native tall images can exceed the viewport; fit/zoom controls are for inspection, not installed UV or display calibration.

`Verify-InspectorCaptures.ps1` binds tour records to a previously independently verified source pixel corpus, uses WIC to decode each captured PNG, checks readback hashes and compares the native visible source region exactly. It refuses incomplete tours, duplicate states, unknown projections, non-native scale, unsafe filenames and ambiguous source identities. T026's proof covers 19 images/six modes/81,469,440 visible pixels. It does not qualify fit/zoom, physical input, installed shaders/fonts, complete atlases, geometry or animation. See [T026](../tasks/T026-source-image-inspector.md).

`image_structure_probe <install> <manifest> <selection> <new-private-report>` uses the same full-source admission and selected CPU profile. It records RGBA histograms, per-bit counts, equal RGB pairs and hidden RGB at zero alpha, then checks bounded IMGD headers in the selected image-bearing BAR originals. `Verify-ImageStructure.ps1` independently derives bit counts from retained source-traced distributions and reconstructs originals through the pinned storage verifier to compare header scalars, region hashes and HD links. These are structural observations; no packed font bank, glyph meaning, palette/swizzle rule or installed shader is inferred. T027 corrects the root internal-image lead to IMGD; full TIM2 decoding remains unimplemented.

T028 adds an optional fifth argument, an existing private IMGD pixel directory. This explicitly requests the bounded `imgd_indexed8_linear_ps2_palette_v1` CPU profile: version 256, GS indexed-8, linear indices, a complete 256-color palette and known flag bits. It preserves original indices, permutes palette index bits 3/4, expands alpha with saturation, and writes new numeric BMP/RGBA/index/palette inspection files. Other routes reject instead of falling back. `Verify-ImgdPixels.ps1` executes the pinned unchanged palette method, independently reconstructs source bytes and checks every index, palette byte, RGBA byte and channel statistic. The selected root image's 32,768 pixels match; installed interpretation, other formats/swizzling and font routing remain pending.
