## Steps and implementation

1. Headless Ghidra 12.1.4 (read-only copy of an existing private project)
   listed the world map classes from RTTI (`worldmap::*`, `dk::WM_*`), dumped
   their vtables and decompiled the whole world map code range and the
   routines it calls. The function list is in the private spec; one GitHub
   issue per part was opened (#84–#89) and linked from #81.
2. `source/data/src/world_map.rs` reads the `00progress.bin` tables `wmky`,
   `wldf` (with its scripts), `epsd`, `wlds`, `link` and `dark`, the
   `70landing.bar` `land` table and `00worldpoint.bin`.
3. `source/game/area/src/world_state.rs` holds the world map's save fields
   and rules: world records (FUN_1403f1e20 / FUN_1403f1e30), symbol slots
   (FUN_1403f1e10), world-event bits and queue (FUN_1403df1b0, FUN_1403df2e0,
   FUN_1403df010, with the 0x25/0x2a/0x2d/0x2e gates and the hold flag of
   FUN_14039ac80), the event script operations (FUN_1403deb40), episode bits
   (FUN_1403f0810, FUN_1403f08e0, FUN_1403f08c0, FUN_1403f0b20), the link
   table (FUN_1403f0ea0), menu flags (FUN_1403e3930 / FUN_1403e3910), world
   points (FUN_1403f2270, FUN_1403f2110, FUN_1403f2190, FUN_1403a5540's point,
   the world point objects' touch), the landing grid (FUN_140394550), the
   default landing (FUN_1403e4190), the visit counts (FUN_14038d330 /
   FUN_14038d2c0), the new-game event (FUN_1403df060), the world map's queued
   events (FUN_14038dc60) and the world map entry (FUN_140154e20).
4. `area::progress`: a flag set now runs that tail of FUN_14039afc0; ops 8, 9
   and 13 are carried out; the world-0x10 block table (FUN_1403a53a0) joins the
   'dsa' check.
5. `save::state::Persistent` reads and writes the full world records, world
   points, menu flags, world events and queue, symbol slots, episode bits and
   the draw-group set.
6. The area loader gives the progress the tables and runs the new-game event
   before setting the configured story flags.
