## What the executable does

Each world has a 4-byte party table at save+0x3534 + 4·world: slot 0 Sora, 1 and 2 active, 3 reserve; bits 0..4 the member's type,
0x12 empty, bit 7 locked (FUN_1403e37c0). The camp swaps a working copy, and FUN_14036b460 writes it back when the camp closes.
